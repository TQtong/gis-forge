# 2.5D 统一地表修复

2.5D 中每个可见瓦片只有一张地表。影像贴在地表网格上，高程未加载或没有覆盖时网格高度为零；高程到达后更新同一网格。地形模块不创建渲染管线、不下载第二份底图，也不提交地图绘制命令。

## 问题与修改

| 问题 | 原因 | 修改 |
| --- | --- | --- |
| 上下两张地图 | RasterTileLayer 的零高度平面和 CesiumTerrainLayer 的贴图三角网同时绘制 | Map25D 改用 TerrainElevationLayer 提供高程，RasterTerrainSurface 负责唯一地表 |
| 远处缺块 | 固定级别、固定覆盖半径，超过瓦片预算时直接截断 | 透视四叉树按视锥和投影大小细化；预算限制细化程度，保留远处粗瓦片 |
| 半山腰向山下看出现大片黑洞 | 远裁面按相机到山坡目标的距离计算，忽略目标海拔与山下的高差；高倍缩放时仅能看到几十米 | 按实际相机高度、最低地面和视锥上沿推导远裁面；接近地平线时以地图范围限制，覆盖远处山脊 |
| 静止时中心地形闪烁、瓦片数反复相差 3 块 | 整数缩放时中心瓦片正好落在细分阈值；浮点误差触发父瓦片与四个子瓦片交替，相机又读取显示网格的插值高度，形成反馈 | 细分/合并使用 110%/90% 双阈值与浮点容差，两个调度器保留上次细分状态；相机目标读取数据源高程，显示网格只参与拾取和避碰 |
| 连续高程更新时突然跳高 | 新过渡从上次的目标高度开始，无关瓦片加载也会重启过渡 | 从当前显示高度接续过渡；高度未变化的网格只更新版本，不重传顶点或重启动画 |
| 相机穿地 | 相机围绕海拔零旋转，未使用实际高程 | 轨道目标跟随地表；检查相机及近裁面附近高程，保留至少 5 米净空，必要时同时扩展远裁面 |
| 拖拽、滚轮定位漂移 | 按零高度平面反投影，滚轮修改状态后仍使用旧矩阵 | 使用当前矩阵与渲染地表求交，排除天空方向的反向交点 |
| 缩放期间重复网格、加载积压 | 旧可见集合与新集合直接合并；缺失瓦片额外加载四个子瓦片 | 统一地表保留不重叠的显示瓦片，复用祖先纹理；不再为占位增加四倍网格/请求 |
| 取消后无法恢复、短暂断网变成永久缺图 | 取消后条目停留在 loading；每帧调度绕过重试退避 | 恢复无请求的 loading 条目，执行退避，临时错误不会被当作永久缺失 |
| 窗口变化后覆盖不完整 | 图层保存初始化时的画布尺寸 | LayerContext 动态提供 CSS 尺寸；尺寸和透视姿态变化触发重新调度 |

高程使用原始 quantized-mesh 三角形的空间索引和插值，不使用扩散填洞的高程栅格。显示地表使用 64×64 网格、短裙边和高程过渡，GPU 缓存按显示瓦片复用。相机防碰撞同时考虑最新数据与正在过渡的显示高度。

远裁面与两种瓦片调度共用包含高程夸张系数的高度范围。尚无数据时使用保守的地球高程范围（原始米制 -12000～9000）；已下载数据超出范围时扩大边界。没有地形图层时为零高度。范围或投影改变会立即重新调度。拾取通过视图基向量构造射线，以近裁面为尺度进行对数步进，防止扩大远裁面后跳过近处山坡。

2026-09-14 按用户提供的 `[116.0399, 40.0467] / zoom 22 / pitch 48.7° / bearing 218°` 复现：2000×1150 视口下旧远裁面约 65 米，山谷大片缺失；只修改远裁面即可恢复山谷。正式修复在 1400×900 视口下远裁面约 39.3 千米，向下看的画面无黑色缺口。两个视口的碰撞约束会改变实际俯仰角，因此裁剪数值不同。

同日用户视频显示 `zoom 13 / pitch 0° / bearing 280.5°`，74～77 是可见瓦片数。在附近的 `[115.8647, 39.895]`、1560×1200 视口复现同类问题：120 帧中瓦片数逐帧交替为 75/78，目标高程在约 1073.214/1073.706 米间交替，而数据源版本始终为 189。修复后将该视角纳入浏览器测试：加载和过渡结束后静置 5 秒，相机矩阵、目标高程及瓦片数都必须保持不变，前后截图必须逐字节相同。

## 验证

- `npm test`：29 个文件、283 项测试通过。包括山谷高差、远处山脊、拾取、瓦片覆盖，以及整数缩放稳定性、细分/合并滞回、相机与显示网格解耦、连续高程过渡。
- `npm run build`：通过。Vite 仍提示主包超过 500 kB。
- `npm run check:deps`：无分层依赖违规。
- 浏览器：真实 Edge/WebGPU 和现有 OSM、地形服务；验证山地、85° 近景、用户的半山腰视角、静止抖动复现视角、无高程区域、跨区域返回、滚轮/拖拽、尺寸变化、地形隐藏/恢复和销毁。
- 浏览器断言：一个画布、可见瓦片不超过 200、没有旧平面绘制、相机在地表上方、无未捕获 WebGPU 错误。
- 半山腰视角额外检查截图像素：所有视线均向下时，黑色缺口占比必须小于 0.1%，避免仅检查瓦片数量而漏掉实际画面被裁剪的问题。

运行 `npm run dev` 后打开 `/tests/browser/terrain25d.html` 可手动复查。自动检查使用 `node tests/browser/verify-terrain25d.cjs`，需要 Playwright；也可通过 `PLAYWRIGHT_PATH` 指定已安装的 Playwright 包目录。`TEST_BASE_URL` 可覆盖默认的 `http://localhost:3010`，`BROWSER_CHANNEL` 默认 `msedge`。

自动检查的截图和诊断写入被 Git 忽略的 `artifacts/terrain25d.local/`。网络检查使用真实远程服务；其加载耗时会受网络和服务响应影响，不构成与 deck.gl 的性能基准对比。
